# Red-Dead-Redemption-PS3-No-Water-Death-Mod
A PS3 mod for Red Dead Redemption GOTY that disables John Marston's instant death in deep water. Tested on BLUS30758 Update 1.01 And a real ps3 hardware


NOTICE: THIS INSTALLATION METHOD ONLY WORKS WITH THE GOTY EDITION
(BLUS30418 01.00 for the main game and BLUS30758 for the 01.01 update).

1- Update your game to the latest version.

2- Go to /dev_hdd0/game/ and find your game update folder.
   Mine is BLUS30758.

3- Go to:
   /dev_hdd0/game/BLUS30758/USRDIR/

   Back up your original RDR2.self, then replace it with the modded one.

That's it. Launch the game and enjoy :)
